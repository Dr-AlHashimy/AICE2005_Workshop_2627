# AICE2005 Workshop

Starter materials for the AICE2005 workshop sessions.

## Using this in your own project

Pull this repo into your own project as a remote to bring in updates as they're published:

```bash
git remote add workshop https://github.com/Dr-AlHashimy/AICE2005_Workshop_2627.git
git pull workshop main --allow-unrelated-histories
```

Or clone it standalone to explore on its own:

```bash
git clone https://github.com/Dr-AlHashimy/AICE2005_Workshop_2627.git
```

## Instructions

1. Conduct a stakeholder mapping exercise — identify at least one stakeholder for each quadrant. Use [`W2/_template/stakeholder-mapping-template.md`](W2/_template/stakeholder-mapping-template.md).
2. Amend your existing use case diagram to show how these stakeholders influence the system.
3. Fill in your functional requirements table. Use [`W2/_template/functional-requirements-template.md`](W2/_template/functional-requirements-template.md).
4. Fill in your non-functional requirements table. Use [`W2/_template/nonfunctional-requirements-template.md`](W2/_template/nonfunctional-requirements-template.md).
